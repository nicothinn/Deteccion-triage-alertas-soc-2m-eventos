\begin{frame}{1. Problema: ¿qué abordamos?}
\textbf{Triage de alertas SOC}: dado un evento de seguridad, predecir su tier
(\texttt{benign} / \texttt{suspicious} / \texttt{malicious}) con probabilidades,
hints MITRE ATT\&CK y decisión operativa (\texttt{escalar} vs \texttt{monitorear}).
\begin{itemize}
\item Entrada: 1 evento (campos + mensaje crudo + vecindario $\pm$5\,min).
\item Salida: $(y, p)$ + técnicas + triage, en $<50$\,ms para rankear la cola.
\end{itemize}
\end{frame}

\begin{frame}{1. Motivación: ¿por qué importa?}
\begin{itemize}
\item \textbf{Volumen}: 2,011,674 eventos en 6 días, 4 orgs, 19 productos — imposible a mano.
\item \textbf{Desbalance extremo}: solo 0.38\% malicious (IR 245:1); el accuracy miente (94\% con siempre-benign).
\item \textbf{Contexto}: decidir exige mensaje + MITRE + cadena, no solo un score (disposition $=$ \texttt{Unprocessed} en 2,005,877/2,011,674).
\item Ground truth = correlación automática de Precinct: oráculo fuerte pero imperfecto.
\end{itemize}
\end{frame}

\begin{frame}{2. Literatura (1/3): panorama}
\begin{itemize}
\item \textbf{Provenance-graph IDS}: NODLINK (NDSS 24, APT online), KnowHow (NDSS 26, interpretable),
FLASH (S\&P 24, GNN temporal), threaTrace/GraphSAGE (base de M3).
\item \textbf{CTI + LLM}: OMNISEC (RAG), PROVSYN (síntesis contra desbalance), TRAM MITRE (mapeo a ATT\&CK + notebooks).
\item \textbf{Imbalance/texto}: Focal Loss, cost-sensitive IDS (FN$>>$FP), TF-IDF gana a BERT con poco dato (P 75\%, F1 64\%).
\item Simuladores: CybORG (despliegue como agente SOC).
\end{itemize}
\end{frame}

\begin{frame}{2. Literatura (2/3): Caso Devign}
\textbf{Devign} (Zhou et al., NeurIPS 2019): GNN sobre grafos de código, binaria a nivel función.
\begin{itemize}
\item Datos manuales $\sim$600 h-persona, 4 libs C (Linux, QEMU, Wireshark, FFmpeg).
\item \textbf{+10.51\% accuracy / +8.68\% F1} vs baselines; +27.99\% F1 vs analizadores; 74.11\% en 40 CVEs nuevos.
\item Lección para nosotros: \textbf{precedente GNN de M3} — grafos + aprendizaje $>$ reglas.
Contraste: ellos etiquetas caras/limpias, nosotros Precinct baratas/ruidosas.
\end{itemize}
\end{frame}

\begin{frame}{2. Literatura (3/3): Caso CVSS-BERT + tabla}

severidad MAE 0.73, 55.3\% match exacto, con saliency explicable. Límite: el CVSS varía según quién asigna.

\begin{frame}{3. Solución y proceso}
\texttt{signals} $\to$ prepro P1--P5 $\to$ M1 rankea / M2 confirma texto / M3 confirma cadena $\to$ fusión $\to$ consola.
\begin{center}

Prepro: one-hot sanitizado, temporales + split temporal 80/20 (anti-leakage), anti-desbalance sin SMOTE, TF-IDF 5k, subgrafo $\pm$5\,min. Modelos + complejidad en el paper.
\end{frame}
